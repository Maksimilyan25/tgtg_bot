# Telegram-бот для анализа изображений

Этот бот предоставляет возможности для анализа изображений с использованием ИИ через прокси-сервер.

## Функционал

1. **Поиск дефектов** — пользователь загружает фото, бот отправляет его на прокси с запросом обнаружить дефекты на изображении. После получения результата — кнопка возврата в меню.

2. **Сравнение с макетом** — сначала загружается эталонное фото (макет), затем фото исследуемого предмета. Бот отправляет запрос на прокси: сравнить два изображения и указать различия. После ответа — кнопка возврата в меню.

3. **Кастомный промт** — бот запрашивает у пользователя текст произвольного вопроса, направляет его на прокси, после получения ответа — кнопка возврата в меню.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Установите переменные окружения:
```bash
export TELEGRAM_BOT_TOKEN="ваш_токен_бота"
export PROXY_URL="http://ваш_прокси_сервер/v1/chat/completions"
```

3. Запустите бота:
```bash
python bot.py
```

## Конфигурация

- `TELEGRAM_BOT_TOKEN` — токен вашего Telegram-бота (получается у @BotFather)
- `API_BASE_URL` — базовый URL API для обработки запросов (по умолчанию: http://localhost:3264)

## Архитектура

- `bot.py` — основной файл запуска бота
- `core/bot.py` — основной класс бота с интеграцией всех компонентов
- `components/` — директория с отдельными компонентами бота:
  - `config.py` — конфигурация и переменные окружения
  - `api_client.py` — логика взаимодействия с API
  - `handlers.py` — обработчики команд и кнопок
  - `image_processor.py` — обработка изображений
  - `user_data_manager.py` — управление пользовательскими данными
  - `state_manager.py` — управление состояниями разговора
- `requirements.txt` — зависимости проекта
- Состояния для обработки различных сценариев:
  - `SEARCH_DEFECTS` — поиск дефектов на изображении
  - `COMPARE_MODEL_1` — загрузка эталонного изображения
  - `COMPARE_MODEL_2` — загрузка изображения для сравнения
  - `CUSTOM_PROMPT` — обработка текстового запроса
